# นโยบายความปลอดภัยและการคุ้มครองข้อมูลการวิจัย (Research Data Security & Privacy Policy)

เอกสารนี้กำหนดข้อปฏิบัติความปลอดภัยอย่างเคร่งครัด สำหรับการพัฒนาและเก็บข้อมูลของโครงการ **RSSI Web Logger** เพื่อป้องกันข้อมูลส่วนบุคคลของผู้เข้าร่วมการทดลอง (PII) และความลับของโครงการรั่วไหลสู่สาธารณะ

---

## 🚫 สิ่งที่ห้ามอัปโหลดขึ้น Git โดยเด็ดขาด (Strict No-Commit List)

| ประเภทข้อมูล | รูปแบบไฟล์ | สาเหตุและผลกระทบ | การป้องกัน |
| :--- | :--- | :--- | :--- |
| **ข้อมูลส่วนบุคคล / รหัสผู้ทดลอง** | `dataset/manifest.json`<br>`**/manifest.json` | มีรหัสนักศึกษา (Participant ID) และ File ID ของไดรฟ์ | กรองออกด้วย `.gitignore` |
| **ชุดข้อมูลโทรมาตรดิบ** | `*.csv`, `*.zip`<br>`dataset/**/*` | ข้อมูลพิกัด GPS, Wi-Fi BSSID และเส้นทางเดิน | กรองออกด้วย `.gitignore` |
| **Google Web App URL / Secret** | `.env`, `.env.local` | ป้องกันผู้อื่นแอบยิงคำสั่งดึงข้อมูลงานวิจัยทั้งหมด | ใช้ `.env.example` เท่านั้น |
| **เปเปอร์วิชาการลิขสิทธิ์** | `*.pdf`, `docs/*.pdf` | เสี่ยงต่อการละเมิดลิขสิทธิ์ของสำนักพิมพ์ (IEEE/Elsevier) | กรองออกด้วย `.gitignore` |

---

## 🔒 แนวทางการจัดการข้อมูลที่ปลอดภัย

### 1. การเก็บ Web App URL ในเครื่อง (Local Only)
* URL ของ Google Apps Script ที่ใช้ดึงข้อมูล ต้องถูกบันทึกไว้ในไฟล์ `.env` ที่เครื่องแล็ปท็อปเท่านั้น:
  ```env
  DOWNLOADER_GAS_URL=https://script.google.com/macros/s/xxxxxxxxxxxx/exec
  ```
* ห้ามเขียน Hardcode URL ลงในสคริปต์ที่ถูก Track ด้วย Git

### 2. การจัดเก็บชุดข้อมูล (Dataset Storage)
* ไฟล์ CSV และ ZIP ที่ดาวน์โหลดมา จะถูกจัดเก็บไว้ในโฟลเดอร์ `dataset/` ในเครื่องแล็ปท็อป
* โฟลเดอร์ `dataset/` จะมีเพียงไฟล์ `.gitkeep` เท่านั้นที่ถูกติดตามใน Git เพื่อรักษาโครงสร้างโฟลเดอร์

### 3. การตรวจสอบก่อน Commit
* รันคำสั่ง `git status` ทุกครั้งก่อน `git add`
* หากพบไฟล์ในกลุ่ม `dataset/`, `manifest.json`, `.env` หรือ `*.pdf` ปรากฏใน Untracked files ให้หยุดและตรวจสอบ `.gitignore` ทันที
